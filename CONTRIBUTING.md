# Contributing

Use ordinary branches and pull requests. Preserve the tested upstream revision
until replacement behavior is demonstrated. Public tests must use synthetic data;
commercial images and derived native code stay outside the repository.

Run unit tests, manifest validation and publication checks before committing.
Record actual test results, distinguishing automated tests from user playtests.
Do not claim a region/revision works without identifying and testing a real copy.
Use a deliberately selected public attribution or GitHub noreply email.
