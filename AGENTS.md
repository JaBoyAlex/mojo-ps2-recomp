# Project rules

Preserve working gameplay. Keep every commercial disc, extracted executable,
translated source, native game executable, save and raw log local under userdata
or outside the repository. Never upload them even to private GitHub repositories.
Never copy AI session state, credentials or personal paths into project files.
Use the explicit publication/release allowlist and both independent checks and
Gitleaks. Scan staged files, full history and release archives before any push.
Do not make the repository public without explicit owner approval.
Report tests honestly. Avoid unnecessary architecture changes and dependency growth.
