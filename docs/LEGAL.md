# Distribution boundary

This project distributes only independently authored integration tools and
properly licensed helper software. Users supply their own legally obtained PS2
disc. No rights to the commercial game or trademarks are asserted or granted.

The generated native game executable contains translated original game code.
Local generation does not establish redistribution rights. Never upload it, the
disc, extracted ELF/IRX/resources, generated C++, memory dumps or gameplay assets
to Git, Git LFS, issues, Actions artifacts or Releases.

Downloaded dependencies retain their upstream licenses and notices. The bootstrap
downloads tools directly from their pinned official sources; the portable release
does not redistribute the full compiler/toolchain. CHD helper license notices are
included under licenses/. No claim is made that an automated audit is legal advice
or proof against every possible copyright/security issue.
